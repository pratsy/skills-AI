# Value Proposition Tester

## Purpose

Evaluate whether the current value proposition is clear, differentiated, and relevant to the target buyer.

## Business problem

Many B2B teams assume their value proposition is clear, but buyers often perceive it as generic, technical, or internally focused.

## Inputs

- current value proposition
- buyer persona
- market context
- competitor reference points
- customer objections or language

## Outputs

- value proposition clarity assessment
- differentiation gaps
- improved value statement options
- buyer-oriented rewrite suggestions

## Use cases

- positioning review
- pitch refinement
- sales enablement updates
- website and landing page copy improvement

## Prompt

“You are a B2B positioning strategist. Evaluate the current value proposition for clarity, buyer relevance, and differentiation. Identify what feels generic or internally focused, and rewrite it in a more precise, buyer-oriented form with measurable business value.”

## Example output

- Current message: efficient workflow software for sales teams
- Gap: too generic, lacks urgency or business outcome
- Rewritten version: reduce deal-cycle friction and improve pipeline visibility with a single operating layer for GTM execution

## Evaluation

- Message is precise and differentiated
- Buyer pain and outcomes are explicit
- It avoids feature-heavy or generic statements
- It aligns with both marketing and sales communication
