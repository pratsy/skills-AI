# Landing Page Copy Optimizer

## Purpose

Improve landing page clarity, conversion focus, and value articulation to increase buyer comprehension and action completion.

## Business problem

Landing pages often fail because the message is too broad, too feature-heavy, or disconnected from the buyer's actual pain and buying triggers.

## Inputs

- headline and CTA
- page copy
- audience segment
- campaign offer
- conversion goal
- messaging context

## Outputs

- improved headline options
- revised CTA suggestions
- stronger value proposition framing
- copy recommendations for higher conversion clarity

## Use cases

- campaign landing pages
- product pages
- lead-gen forms
- offer pages
- homepage conversion improvements

## Prompt

“You are a B2B conversion strategist. Review the provided landing page copy and optimize it for clarity, urgency, and conversion. Improve the headline, CTA, and value framing so they speak more directly to the buyer's pain and decision context. Return a revised version and explain the reasoning behind each change.”

## Example output

- Revised headline: Reduce pipeline friction and improve forecast confidence with a single GTM operating layer
- CTA revision: Book a strategy review
- Improvement: moved from generic description to operational business value and reduced feature clutter

## Evaluation

- Copy is clear and buyer-relevant
- CTA is action-oriented and specific
- Value statement is outcome-driven rather than feature-driven
- Output is useful in both campaign and conversion analysis contexts
