# ICP Refinement Agent

## Purpose

Refine the ideal customer profile using customer data, market context, and behavioral signal.

## Inputs

- CRM data
- conversion patterns
- ICP definitions
- customer feedback
- product usage patterns

## Outputs

- refined ICP summary
- key buying triggers
- prioritized segments
- low-fit segments to avoid

## Prompt

“You are a B2B go-to-market strategist. Review the provided customer and market data and refine the ideal customer profile. Highlight segments with the strongest fit, buying triggers, and targetability; identify any segments to deprioritize.”

## Example

- Best-fit segment: mid-market SaaS companies with 50–500 employees
- Priority trigger: scaling inefficiencies and fragmented pipeline management
- Deprioritize: low-ACV, low-engagement accounts
