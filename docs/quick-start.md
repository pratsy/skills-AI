# 5-minute quick start

This repo is useful when a team wants better signal and clearer action around real GTM work.

## Step 1: identify the business problem

Choose the problem you are currently facing:

- weak account prioritization
- poor pipeline quality
- unclear messaging
- weak conversion or high funnel drop-off
- risky renewals or forecast uncertainty
- competitor or market confusion

## Step 2: choose the right skill pack

- Sales: account prioritization, deal risk, executive readiness, multi-threading
- Marketing: funnel friction, brand perception, content gap analysis, messaging
- RevOps: pipeline health, forecast bias, handoff quality
- GTM: competitive signals, market shifts, strategic account planning

## Step 3: read the skill README

Each skill includes:

- purpose
- inputs
- outputs
- prompt structure
- example result
- source basis

This makes the skill easier for both business teams and technical builders to evaluate.

## Step 4: use one of the prompt packs

Use the plain-English prompts in `docs/prompt-packs.md` for a quick business-first test.

## Step 5: turn the output into a real action

Good output should help you answer:

- what is the problem?
- what is the evidence?
- what should we do next?
- who owns the action?

The value is in the action, not the prompt alone.
