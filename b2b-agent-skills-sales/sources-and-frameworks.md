# Public source base and framework references

## Named methodologies used in this pack

These are the specific, checkable frameworks each skill operationalizes — see each skill's "Grounded in" section for which framework applies:

- **MEDDPICC** (extension of MEDDIC, originating at PTC in the 1990s) — the dominant enterprise B2B sales qualification framework
- **SPIN Selling** — Neil Rackham, based on research across 35,000+ sales calls
- **The Challenger Sale** — Matthew Dixon and Brent Adamson (CEB/Gartner research), including the "Mobilizer" concept
- **Getting to Yes** — Roger Fisher and William Ury, the origin of BATNA and principled negotiation
- **The Pyramid Principle** — Barbara Minto, the standard structure for executive/consulting communication
