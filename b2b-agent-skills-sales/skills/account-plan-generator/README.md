# Account Plan Generator

## Purpose

Create a practical account plan that outlines goals, buying context, stakeholders, risks, and next-best actions for strategic accounts.

## Business problem

Many strategic accounts lack a shared plan that maps buying priorities, stakeholder influence, and next-step execution. This leads to inconsistent sales motions and delayed momentum.

## Inputs

- account summary
- account goals
- stakeholders
- buyer context
- competitive context
- current stage and opportunity status

## Outputs

- account plan
- stakeholder map
- risks and dependencies
- recommended next steps
- success milestones

## Use cases

- strategic account planning
- enterprise account reviews
- expansion or upsell scenarios
- executive account briefs

## Prompt

“You are a strategic account planning partner. Build a concise account plan for the following target account. Include the business context, buying process, stakeholders, likely decision criteria, risk areas, and a practical sequence of actions to move the deal forward. The plan should help the sales team coordinate execution across stakeholders.”

## Example output

- Goal: improve operational efficiency and reduce manual pipeline bottlenecks
- Stakeholders: VP of operations, finance lead, IT stakeholder
- Risk: unclear ownership and conflicting priorities between teams
- Next steps: align stakeholder goals, secure executive sponsor, validate implementation roadmap

## Evaluation

- Plan reflects actual account context
- Stakeholder dynamics are considered
- Action plan is realistic and prioritized
- Output is useful for both AE and executive review
