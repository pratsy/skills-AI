# Lead Prioritization Agent

## Purpose

Identify which accounts should receive immediate sales attention based on fit, urgency, buying signal, and commercial value.

## Inputs

- CRM records
- firmographic data
- engagement signals
- intent data
- historical conversion patterns

## Outputs

- ranked account list
- recommended actions
- risk signals
- next-best steps

## Prompt

“You are a senior B2B sales strategist. Rank the following accounts by conversion likelihood, fit, urgency, and strategic value. Return a prioritized list with rationale and recommended next actions.”

## Example

- Account A — high fit, active buying signal, immediate outreach recommended
- Account B — medium fit, nurture sequence recommended
- Account C — poor fit, deprioritize
