# Objection Response Coach

## Why this skill exists

Most objection handling is reactive and generic.

A sales team may respond to objections in the moment, but miss the deeper pattern behind them. This skill helps identify the real source of buyer resistance and build a more useful response strategy.

## Business objective

This skill helps the team answer:

> What is the customer really worried about, and how do we respond in a way that addresses the actual concern rather than just the surface-level objection?

## Expert memory layer

Strong sales teams build memory around objection patterns:

- common buyer concerns by segment or use case
- objections that signal weak buying readiness versus strong risk
- where the message is not landing because the value story is incomplete
- which objections require proof, repositioning, or executive alignment

This skill captures those patterns in a structured response playbook.

## Inputs

- customer objections and sales notes
- buyer persona and context
- competitor comparisons or alternatives
- deal stage and stakeholder concerns
- previous objection handling examples

## Decision logic

A strong objection response should be based on:

1. what the objection actually means
2. whether it is a value issue, trust issue, or process issue
3. what proof or framing resolves it
4. whether the right person should answer it
5. how the response changes the buying momentum

The best response is not defensive; it is diagnostic and persuasive.

## Common failure patterns

- answering the objection with a scripted response instead of the real issue
- treating pricing objections as pure discount conversations
- missing signal that the customer is really skeptical about implementation or risk
- giving the same answer to different stakeholder types
- failing to align the answer with the broader value story

## Outputs

- objection summary
- root cause assessment
- response strategy
- proof points or evidence to use
- recommended follow-up question or next step

## Example result

### Objection: “This feels too complex to implement.”
- Root cause: buyer is worried about operational disruption and internal resource strain.
- Best response: frame the solution around phased rollout, low-friction setup, and measurable implementation support.
- Proof points: customer case studies, rollout plan, and implementation timeline.

## Recommended prompt

> You are a senior sales coach and objection handler. Review the customer objection, deal context, and stakeholder dynamics. Explain the likely underlying concern, identify the best response strategy, and propose a practical, persuasive answer backed by relevant proof or reframing.
