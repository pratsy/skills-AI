# Overview

This repository acts as the flagship library for B2B revenue AI skills.

The goal is to create reusable, high-signal playbooks for AI agents working in sales, marketing, RevOps, and GTM strategy.

## Design philosophy

- Business first, tooling second
- Real sales and marketing workflows over generic AI prompts
- Clear evaluation criteria for every skill
- Modular skill architecture for composition

## Core principles

1. Every skill solves a real GTM problem.
2. Each skill includes a prompt, example, and rubric.
3. The project is organized by function, not by random topic.
4. The system is built to scale with more domain-specific skill packs.

## Skill taxonomy

- Sales: prospecting, qualification, negotiation, forecasting
- Marketing: ICP, messaging, campaign optimization, ABM
- RevOps: pipeline health, forecasting, reporting, system automation
- GTM Intelligence: market research, competitor insight, expansion signals

## Future extension

This repo is meant to be the central public-facing library. Domain-specific repositories can be created later for deeper specialization.
