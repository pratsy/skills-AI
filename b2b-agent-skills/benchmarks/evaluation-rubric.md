# Evaluation Rubric

Every skill should be assessed against the same rubric.

## Scoring dimensions

1. Business relevance
2. Practical actionability
3. Clarity of reasoning
4. Specificity of output
5. Consistency with real GTM workflows
6. Usability in the right job context

## Score interpretation

- 5 = Excellent and highly actionable
- 4 = Strong and useful with minor adjustments
- 3 = Good but requires human review
- 2 = Weak or generic
- 1 = Not useful for the intended workflow

## Usage guidance

Use this rubric to compare skills, improve prompts, and create evaluation baselines across repos.
