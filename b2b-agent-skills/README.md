# B2B Agent Skills for Sales, Marketing, and GTM

Research-informed AI skill libraries for B2B sales, marketing, revenue operations, and go-to-market teams.

This project is designed to help AI agents act like experienced revenue operators, not generic copilots.

## What this repo contains

- Sales skill packs
- Marketing skill packs
- RevOps and GTM intelligence playbooks
- Prompt templates
- Example outputs
- Evaluation rubrics
- Source-backed frameworks and practitioner-informed methods

## Why this project exists

Most AI tools are generic. Most teams need operational intelligence for:

- lead prioritization
- discovery conversations
- pipeline health analysis
- ICP refinement
- campaign optimization
- deal risk assessment
- messaging clarity
- competitive monitoring

This repo focuses on the actual motions that matter in B2B revenue execution and translates them into structured, reusable skill patterns.

## Research and expert-informed design

This library is intentionally structured to reflect a practitioner-first, research-informed model of B2B revenue execution. It synthesizes:

- revenue operations practices
- sales and marketing operating frameworks
- market and ICP segmentation methods
- campaign and funnel optimization patterns
- strategic GTM analysis methods

The content is designed to feel operational and business-grounded rather than generic prompt generation.

Browse the `skills/` directory and choose a playbook relevant to your business motion. Each skill includes:

- problem statement
- business use case
- inputs
- expected output
- prompt template
- evaluation rubric
- source references

This is a library of high-value B2B revenue AI playbooks designed for real operating contexts and informed by public B2B GTM practice.
