# ICP Refinement Agent

## Purpose

Refine the ideal customer profile using customer data, product signal, and market reality.

## Business problem

Marketing teams often target broad audiences without enough signal to distinguish high-value segments from low-fit buyers.

## Inputs

- CRM data
- customer segmentation
- product usage data
- win/loss analysis
- market trends

## Outputs

- refined ICP
- key customer segments
- valuable buying triggers
- low-fit segments to avoid

## Use cases

- ICP updates
- ABM targeting
- market segmentation
- campaign planning

## Prompt

“You are a B2B go-to-market strategist. Analyze the provided customer and market data and refine the ideal customer profile. Identify the highest-value segments, common buying triggers, and segments that should be deprioritized. Return a concise ICP summary with recommended targeting strategy.”

## Example output

- Best-fit segment: mid-market SaaS companies with 50–500 employees
- Main trigger: scaling inefficiencies and manual process bottlenecks
- Best message: reduce pipeline inefficiency and improve forecasting visibility
- Deprioritize: low ACV, low usage, low expansion potential

## Evaluation

- ICP is specific and actionable
- Recommendations align with actual customer patterns
- Output helps targeting and messaging
