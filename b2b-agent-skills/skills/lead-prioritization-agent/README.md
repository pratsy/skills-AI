# Lead Prioritization Agent

## Purpose

Identify which accounts should receive immediate sales attention based on fit, urgency, buying signal, and commercial value.

## Business problem

Sales teams often spend time on low-probability accounts. This skill helps rank leads based on real conversion potential and strategic value.

## Inputs

- CRM records
- firmographic data
- lead score data
- product usage or engagement signals
- historical win/loss patterns

## Outputs

- ranked lead list
- reasoning for each account
- recommended next action
- risk flags

## Use cases

- SDR queue prioritization
- outbound list refinement
- territory planning
- strategic account targeting

## Prompt

“You are a senior B2B sales strategist. Review the following lead list and rank the accounts by conversion likelihood and commercial value. Use fit, urgency, buying signals, historical performance, and strategic relevance. Return a ranked list with rationale and recommended action for each lead.”

## Example output

- Account A: high fit, active buying intent, assign to AE immediately
- Account B: good fit but lower urgency, nurture with sequence
- Account C: poor fit, deprioritize

## Evaluation

- Ranking reflects real buying signals
- Output is actionable
- Mid-tier accounts are not over-prioritized
- Recommendations align with GTM strategy
