# Lead Prioritization Agent

## Why this skill exists

Sales teams often waste attention on leads with weak buying potential. The result is low productivity, slower cycles, and uneven pipeline quality.

This skill helps rank opportunities based on commercial value, fit, urgency, and buying signal so reps focus on the accounts most likely to convert or expand.

## Business objective

This skill helps the team answer:

> Which leads deserve immediate attention, which should be nurtured, and which should be deprioritized?

## Expert memory layer

Experienced sales teams build memory around signals such as:

- firmographic and behavioral fit
- urgency and timing pressure
- engagement quality and buying intent
- historical win patterns and segment performance
- strategic value versus operating cost of pursuit

This skill converts those patterns into a disciplined lead-ranking model.

## Inputs

- CRM records and lead attributes
- firmographic and firm-level fit data
- engagement or product usage signals
- historical win/loss patterns
- buying-stage context and urgency indicators
- segment or territory strategy context

## Decision logic

A useful prioritization model should weigh:

1. fit: does the account match the target profile?
2. urgency: is the problem pressing enough to justify action?
3. engagement quality: are there credible buying signals?
4. commercial value: is the account strategic or high-value?
5. conversion realism: is this a strong bet versus a low-probability chase?

The objective is to create a ranking that supports resource allocation, not just a broad list of accounts.

## Common failure patterns

- prioritizing based on volume instead of conversion probability
- overrating leads with weak buying intent
- ignoring historical performance by segment or source
- treating all active leads as equally urgent
- using generic score thresholds without business context

## Outputs

- ranked lead list
- rationale for each priority tier
- recommended next action by account
- deprioritization or nurture guidance
- strategic or risk flags for leadership

## Example result

### High-priority lead
- Strong fit for target segment
- Engagement indicates clear buying intent
- Commercial value is meaningful and strategic
- Recommendation: route to AE immediately with tailored discovery and executive outreach

### Medium-priority lead
- Good fit but limited urgency
- Recommend nurture with trusted triggers and continued monitoring

## Recommended prompt

> You are a senior B2B sales strategist. Review the lead list and rank each account based on fit, urgency, buying signal, and commercial value. Return a prioritized list with rationale and recommended action for each lead, including where to assign immediate attention versus nurture or deprioritize.

## Why this is different from a generic prompt

This is not just “rank my leads.”

It is a practical prioritization model that helps sales teams decide:

- which accounts deserve attention now
- which opportunities are worth nurturing
- which leads are low-quality distractions
- how to allocate scarce sales capacity with better judgment

That is the operational memory behind a useful lead-prioritization skill.
